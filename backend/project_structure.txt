Development order

I strongly recommend not starting with Kubernetes immediately. Build the system in layers:

Phase 1 — Architecture

Create the parent project structure
Create Eureka Server
Create API Gateway
Create the microservices
Configure Eureka registration

Phase 2 — Backend

MySQL databases
JPA entities/repositories
REST controllers
Service layer
Inter-service communication

Phase 3 — Security

Auth service
User registration/login
JWT generation
Spring Security
Gateway JWT authentication
Role-based authorization: USER / ADMIN

Phase 4 — Frontend

Angular project
Bootstrap
Home
About
Contact
Tours
Tour details
Login/Register
User dashboard
Admin dashboard

Phase 5 — Testing

Test every REST endpoint with Postman
Test JWT authentication
Test service-to-service communication
Test Angular → Gateway → Microservice

Phase 6 — Docker

Dockerfile for each Spring Boot service
Angular Dockerfile
MySQL container
Docker networking
Test the complete application with Docker

Phase 7 — Kubernetes

Deployments
Services
ConfigMaps
Secrets
Eureka deployment
Gateway deployment
Microservice deployments
MySQL
Angular
End-to-end Kubernetes testing

This gives us a proper microservices project, rather than simply taking the previous monolithic Travel Agency application and putting Docker around it.

Next step should be the project structure first, then we create Eureka Server and get that running before touching the other services.
